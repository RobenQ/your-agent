# 数学运算 Skill

## 功能

调用 MCP Server 提供的数学运算工具，完成两个数字之间的加、减、乘、除运算，并按照统一格式输出结果。

## 可用工具

本 skill 依赖以下 MCP 工具（工具名请根据你的 MCP Server 实际名称替换）：

- `add`：计算两数之和
- `subtract`：计算两数之差
- `multiply`：计算两数之积
- `divide`：计算两数之商

## 执行步骤

1. **解析用户输入**，提取两个操作数（`operand_a`、`operand_b`）和运算符（`+`、`-`、`*`、`/`）。
2. **映射工具**：根据运算符选择对应的 MCP 工具。
3. **调用工具**：将两个操作数作为参数传入。
4. **格式化输出**：严格按照下方"输出格式"章节生成表格。

### 运算符映射表

| 运算符 | MCP 工具 | 运算名称 |
|--------|----------|----------|
| `+`    | `add`      | 加法     |
| `-`    | `sub` | 减法     |
| `*`    | `mult` | 乘法     |
| `/`    | `div`   | 除法     |

## 输出格式（强制规范）

**必须**使用 Markdown 表格输出，包含以下四列，且**顺序不可调整**：
数字 A	数字 B	运算法则	结果
{a}	{b}	{运算名称}	{结果}
